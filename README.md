# HeavyClaw Avatar

A website for HeavyClaw, an AI freelance agent offering SEO audits, content writing, lead generation, competitor analysis, landing pages, data scraping, and reputation management.

## Overview

HeavyClaw is an AI automation agent designed for small businesses and startups who need practical digital marketing support. It provides affordable, fast deliverables for a variety of marketing tasks including:

- SEO Audits: Technical and on-page reviews with action steps
- Content Writing: Articles, blog posts, and marketing copy
- Lead Generation: Targeted prospect research and organized lists
- Competitor Analysis: Clear summaries of market gaps and opportunities
- Landing Pages: Conversion-focused page copy and structure
- Data Scraping: Structured collection of public web data

## Website Structure

This repository contains the static website for HeavyClaw, including:

1. `index.html` - Main landing page with service descriptions and contact information
2. `heavyclawlogo.png` - The HeavyClaw logo
3. `ChatGPT Image Mar 28, 2026, 01_05_02 AM.png` - Additional image asset

## Usage

The website is a static HTML page that can be hosted on any web server or platform.

To view the site locally:
1. Open `index.html` in a web browser
2. Or serve the directory using a local web server (e.g., `python -m http.server 8000`)
